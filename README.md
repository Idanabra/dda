# אבחון הגילוי הדיגיטלי (Digital Discovery Assessment – DDA)

כלי אינטראקטיבי בעברית (RTL) המדגים את מבנה ה-Digital Discovery Assessment (DDA) המשמש בשלב הגילוי (Discover) של מתודולוגיית SAP Activate עבור SAP S/4HANA Cloud Public Edition.

עמוד HTML יחיד, ללא תלויות בנייה (build-free) — ניתן לפתוח ישירות בדפדפן או לפרוס כאתר סטטי.

## שלבי הכלי

1. **פתיחה** – הסבר על ה-DDA ומיקומו בתהליך.
2. **הגדרת פרופיל מהירה (Quick Qualification)** – פרטי ארגון, תעשייה, גיאוגרפיה, מערכת קיימת, לוח זמנים ויעדי מעבר.
3. **גילוי מפורט (Detailed Discovery)** – סקירת תחומי פעילות (Lines of Business) ובחירת תרחישים עסקיים (Scope Items) עם עדיפות, שלב יישום והערות.
4. **סיכום ודוח היקף** – מפת כיסוי לפי תחום (radial micro charts בסגנון SAP Fiori), טבלת תרחישים שנבחרו, והדפסה/שמירה כ-PDF.

## הרצה מקומית

פתיחת `index.html` ישירות בדפדפן מספיקה — אין שרת, build step או תלויות npm.

```bash
open index.html      # macOS
xdg-open index.html  # Linux
start index.html      # Windows
```

## פריסה (GitHub Pages)

1. דחפו (push) את הריפו ל-GitHub.
2. ב-Settings → Pages, בחרו את הענף `main` והתיקייה `/ (root)`.
3. האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

## הערה חשובה

הכלי בנוי בהשראת מבנה ה-DDA הרשמי של SAP (בחירת פתרון, לוקליזציה, ו-16 תחומי פעילות עם מאות תרחישים עסקיים), עם מבחר תרחישים מייצג לכל תחום לצורך תרגול ותיאום ציפיות עם לקוחות. **זהו כלי הדגמה בלבד** — עבור אבחון רשמי ומחייב מול SAP יש להשתמש בכלי ה-DDA הרשמי דרך הפרטנר או צוות המכירות של SAP.
